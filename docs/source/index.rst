proposal-service documentation
===============================

A FastAPI service that turns a Horizon Europe proposal PDF into structured
work-package data through a three-stage pipeline: table extraction, LLM task
extraction, and assembly.

This site is the **code reference**, generated from the docstrings and
Pydantic models in the source tree. For the live, always-in-sync **HTTP API
contract**, run the service and open Swagger UI at ``/docs`` or ReDoc at
``/redoc``.
